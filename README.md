# 📊 Excel Sales Performance Dashboard

This project demonstrates an end-to-end Business Analytics solution built entirely in Microsoft Excel using a Global Trade dataset.

The workbook showcases data cleaning, data transformation, business calculations, lookup functions, conditional aggregation, Pivot Tables, interactive dashboards, charts, slicers, and VBA automation.

## Features

✔ Data Cleaning

✔ Sales Metrics Analysis

✔ Text Processing

✔ Logical Decision Analysis

✔ Data Lookup & Validation

✔ Conditional Aggregation Analysis

✔ Interactive Pivot Tables

✔ Business Data Visualization

✔ VBA Automation

✔ Executive Sales Dashboard
